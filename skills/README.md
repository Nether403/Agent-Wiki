# Optional skill playbooks

These directories are short writing playbooks. They are **not** MCP tools and they do not run in CI.

The agent execution contract is root `SKILL.md` (synced to Cursor/Claude/Codex via `pnpm sync:rules`).

If a skill describes Playwright, Storybook, Figma, or video-to-UI pipelines, treat it as research until that code exists in `packages/`.
