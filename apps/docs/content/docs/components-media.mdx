# Media & Synthesis (`ui:media`)

Media components provide rich timeline scrubbing, sound visualization, and video controls.

---

## Curated Components

- **`audio-visualizer`**: Live synthesized acoustic frequency bars with play/pause state toggle.
- **`timeline-player`**: Precision motion timeline controller with frame stepping and timecode display.
