# Creative & WebGL (`ui:creative`)

The Creative category houses experimental shaders, fluid simulations, and generative backgrounds.

Every creative element enforces:
- **Zero-Draft A11y Fallback**: If WebGL context is lost, high-contrast CSS gradients or static SVG fallbacks render immediately.
- **CPU Throttling & Visibility Observers**: Canvas loops automatically pause when tab is in background or scrolled out of viewport.
- **No Blanket Glassmorphism**: Controlled opacity surfaces that maintain WCAG contrast ratios.
