## 🚀 How Agents Consume Skills

AI developer agents automatically load skills via:
1. **Local Skill Directory**: Placed directly in `skills/[name]/SKILL.md`.
2. **Auto-Synchronized Instruction Files**: Compiled into `AGENTS.md`, `CLAUDE.md`, `.cursorrules`, `.cursor/rules/design-wiki.mdc`, `.windsurfrules`, `.codex-plugin/rules.json`, `.openclaw/instructions.md`, and `.hermes/instructions.md`.
3. **CLI Discovery**: Run `npx design-wiki skills` to view available playbooks.
