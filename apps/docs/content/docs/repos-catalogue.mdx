## 2. Ingestion & Codemod Pipeline

When remote code is harvested via `packages/harvester`, it passes through automated AST codemod passes:

1. **Tailwind v4 Remapping** (`tailwind-v4-transform.ts`): Strips legacy `indigo-600` colors and arbitrary pixel overrides (`p-[17px]`), enforcing standard Tailwind CSS v4 `@theme` variables.
2. **DaisyUI Normalizer** (`daisyui-to-tailwindv4-transform.ts`): Replaces DaisyUI component shorthand (`btn`, `card-body`) with tokenized utility classes.
3. **Motion React v12 Upgrade** (`framer-motion-v12-transform.ts`): Migrates imports from `framer-motion` to `motion/react` and enforces spring damping parameters (SLOP-028).
4. **Lucide Standardization** (`lucide-normalizer.ts`): Converts direct package paths to `@/components/ui/` or `lucide-react` tree-shakeable imports.
5. **Anti-Slop Cleaner** (`unslop-codemod.ts`): Eliminates chained type assertions (`as unknown as User`), placeholder comments, and AI clichés.
