# Utility & Micro-Feedback (`ui:utility`)

High-density micro-feedback components for inline status, hotkeys, and loaders.

---

## Curated Components

- **`dot-loader`**: Minimalist 3-dot harmonic oscillation loader for button loading states.
- **`icon-morph`**: Smooth SVG icon state transition (play/pause/check).
- **`keyboard-shortcut`**: Platform-adaptive key combo pill (`Cmd + K`, `Shift + D`).
- **`badge`**: High-contrast status indicator badge.
