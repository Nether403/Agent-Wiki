# AI-Native & Agentic Components (`ui:ai-native`)

As AI agents take an active role in software execution, interfaces must communicate runtime thought, indeterminate latency, and dynamic context windows without resorting to generic chat bubbles or AI clichés.

## 3. Anti-Slop Discipline for AI Interfaces

1. **No Static SLA Claims (`SLOP-047`)**: Never hardcode claims like "Instant 0ms Latency" or "100% Accuracy".
2. **Accessible Token Streaming (`SLOP-043`)**: Always wrap streaming token chunks in `aria-live="polite"` so screen readers announce completions without stutter.
3. **Deterministic Cleanups (`SLOP-044`)**: Cancel all active typing interval timers on unmount.
