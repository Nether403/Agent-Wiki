# Model Context Protocol (MCP) Setup

The `@design-wiki/mcp` server connects your AI coding agent directly to the curated component registry.

### Claude Code Setup

Add to your project's `.claude/mcp.json` or run:

```bash
claude mcp add design-wiki npx @design-wiki/mcp
```

### Cursor Setup

Add into `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "design-wiki": {
      "command": "npx",
      "args": ["@design-wiki/mcp"]
    }
  }
}
```

### Core MCP Tools

1. **`search_components`**:
   Search the catalog by query, category, tags, or taste dial parameters (`minMotionIntensity`, `maxVisualDensity`, `minDesignVariance`).
   ```json
   { "query": "dock", "category": "ui:motion", "minMotionIntensity": 6 }
   ```

2. **`fetch_raw_markdown`**:
   Fetch complete raw Markdown documentation including structured YAML frontmatter contract, technical tags, structural complexity, accessibility specifications, and verified TSX source code. *(Aliases: `fetch_raw_markup`, `get_component_markup`)*
   ```json
   { "name": "floating-dock" }
   ```

3. **`get_installation_commands`**:
   Retrieve the exact programmatic CLI commands (`npx design-wiki add <slug>`, `npx shadcn@latest add ...`), peer npm install strings, import snippets, and step-by-step instructions. *(Aliases: `get_installation_schema`, `get_install_recipe`)*
   ```json
   { "name": "floating-dock", "packageManager": "pnpm", "baseUrl": "http://localhost:3000" }
   ```

4. **`audit_code_slop`**:
   Scan arbitrary user code against the 20 anti-slop rules, checking arbitrary pixel escapes (`p-[17px]`), blanket transitions, and accessibility compliance, receiving a health scorecard (0–100) with line-by-line remediation recommendations.
   ```json
   { "code": "<your-tsx-code>" }
   ```
