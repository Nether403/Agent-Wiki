# Model Context Protocol (MCP) Setup

The `@design-wiki/mcp` server connects your AI coding agent directly to the curated component registry.

### Claude Code Setup

Add to your project's `.claude/mcp.json` or run:

```bash
claude mcp add design-wiki npx @design-wiki/mcp
```

### Cursor Setup

Add into `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "design-wiki": {
      "command": "npx",
      "args": ["@design-wiki/mcp"]
    }
  }
}
```

### Core MCP Tools

1. **`search_components`**:
   Search the catalog by query, category, tags, or taste dial parameters (`minMotionIntensity`, `maxVisualDensity`, `minDesignVariance`).
   ```json
   { "query": "dock", "category": "ui:motion", "minMotionIntensity": 6 }
   ```

2. **`fetch_raw_markup`** *(alias: `get_component_markup`)*:
   Fetch complete, un-truncated production TSX/JSX source code, peer dependencies, and styling recipes.
   ```json
   { "name": "floating-dock" }
   ```

3. **`get_installation_schema`** *(alias: `get_install_recipe`)*:
   Retrieve the complete shadcn v3 registry JSON installation schema, file definitions, and exact CLI install commands (`npx shadcn@latest add ...`).
   ```json
   { "name": "floating-dock", "baseUrl": "http://localhost:3000" }
   ```

4. **`audit_code_slop`**:
   Scan arbitrary user code against the 20 anti-slop rules and receive a health scorecard with line-by-line remediation recommendations.
   ```json
   { "code": "<your-tsx-code>" }
   ```
