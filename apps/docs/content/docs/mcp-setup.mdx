# Model Context Protocol (MCP) Setup

The `@design-wiki/mcp` server connects your AI coding agent directly to the curated component registry.

### Claude Code Setup

Add to your project's `.claude/mcp.json` or run:

```bash
claude mcp add design-wiki npx @design-wiki/mcp
```

### Cursor Setup

Add into `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "design-wiki": {
      "command": "npx",
      "args": ["@design-wiki/mcp"]
    }
  }
}
```

### Windsurf Setup

Add into `.windsurf/mcp.json`:

```json
{
  "mcpServers": {
    "design-wiki": {
      "command": "npx",
      "args": ["@design-wiki/mcp"]
    }
  }
}
```

### OpenAI Codex Setup

Add the MCP server to your Codex plugin configuration in `.codex/config.json`:

```json
{
  "plugins": [
    {
      "name": "design-wiki",
      "command": "npx",
      "args": ["@design-wiki/mcp"],
      "transport": "stdio"
    }
  ]
}
```

### Remote Cloudflare Worker Edge MCP (Universal / Browser / v0)

Deployable to Cloudflare Workers with embedded snapshot catalog (0ms disk access):

```bash
# JSON-RPC Endpoint
https://mcp.design-wiki.dev/mcp

# SSE Stream Endpoint
https://mcp.design-wiki.dev/sse

# Health Check Probe
https://mcp.design-wiki.dev/health
```

## Global Agent Ecosystem Rulepack Distribution

In addition to the MCP server, the Design Agent Wiki distributes the canonical agent execution contract and taste dials to all 11 supported agent platforms automatically:

```bash
# Distribute SKILL.md rules to all 11 supported agent configurations
pnpm sync:rules

# Test compatibility across all 11 platforms
pnpm test:agents
```

This command reads `SKILL.md` from the repository root and writes synchronized rule files to:

| Target File | Agent / Platform |
| :--- | :--- |
| `SKILL.md` | Anthropic / Claude Code / Antigravity |
| `.cursorrules` | Cursor IDE |
| `.cursor/rules/design-wiki.mdc` | Cursor Rules v2 format |
| `.windsurfrules` | Windsurf / Codeium |
| `.github/copilot-instructions.md` | GitHub Copilot |
| `AGENTS.md` | Universal Agent Standard (OpenClaw, Devin, Pi) |
| `CLAUDE.md` | Claude Code Workspace |
| `.codex-plugin/rules.json` | OpenAI Codex / Plugins |
| `.openclaw/instructions.md` | OpenClaw Agent |
| `.hermes/instructions.md` | Hermes Agent |
| `apps/docs/public/SKILL.md` | Remote endpoint for LLM agents |

## Core MCP Tools

All tools are optimized to deliver structured responses well under **15KB**, ensuring high LLM context efficiency and zero truncation:

1. **`search_library` / `search_components`**:
   Search the catalog by query, category, tags, or taste dial parameters (`minMotionIntensity`, `maxVisualDensity`, `minDesignVariance`).
   ```json
   { "query": "dock", "category": "ui:motion", "minMotionIntensity": 6 }
   ```

2. **`fetch_raw_markup` / `fetch_raw_markdown`**:
   Fetch complete raw Markdown documentation or structured TSX markup including structured YAML frontmatter contract, technical tags, structural complexity, accessibility specifications, and verified TSX source code. *(Aliases: `get_component_markup`)*
   ```json
   { "name": "floating-dock" }
   ```

3. **`get_installation_schema` / `get_installation_commands`**:
   Retrieve the exact programmatic CLI commands (`npx design-wiki add <slug>`, `npx shadcn@latest add ...`), shadcn v3 compliant file schemas, peer npm install strings, import snippets, and step-by-step instructions. *(Alias: `get_install_recipe`)*
   ```json
   { "name": "floating-dock", "packageManager": "pnpm", "baseUrl": "http://localhost:3000" }
   ```

4. **`get_dependency_graph`**:
   Return the dynamic DAG dependency topology, topological installation sequence, and required npm peer dependencies for a component or the full registry.
   ```json
   { "name": "pricing-table", "includeMermaid": true }
   ```

5. **`audit_code_slop`**:
   Scan arbitrary user code against the 21 anti-slop rules, checking arbitrary pixel escapes (`p-[17px]`), chained type assertions (`as any as`), unshaded backgrounds (`bg-white`), blanket transitions, and accessibility compliance, receiving a health scorecard (0–100) with line-by-line remediation recommendations.
   ```json
   { "code": "<your-tsx-code>" }
   ```
