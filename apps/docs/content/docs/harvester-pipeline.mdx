# Ingestion Harvester Pipeline

The **Harvester Engine** (`@design-wiki/harvester`) connects the Design Agent Wiki to upstream open-source repositories, ensuring all imported assets are normalized, typed, and guaranteed zero-slop.

## Architecture

```
[Upstream Repos] ──► [1. Cloner] ──► [2. AST Parser] ──► [3. Codemods] ──► [4. Dial Scorer & Slop Gate]
```

### 1. Repository Manifest & Automated Cloner

The cloner manages shallow clones (`git clone --depth 1`) from verified upstream repositories into a local staging sandbox (`staging/clones/`).

Each repository in `KNOWN_REPOSITORIES` (`ast-parser.ts`) is pre-configured with a canonical taxonomy category, default taste dial presets (`defaultDials`), and semantic tag groups. The seven curated library mappings are:

| Library | Category | Core Tags | Default Dials (Var/Mot/Den) |
| :--- | :--- | :--- | :--- |
| **Aceternity UI** | `ui:motion` | `framer-motion, tailwind-v4, micro-interaction` | 6 / 8 / 4 |
| **Canvas UI** | `ui:creative` | `threejs, webgl, framer-motion, interactive` | 9 / 9 / 3 |
| **diagram-design** | `ui:editorial` | `svg, zero-dependency, static, analytical` | 5 / 1 / 9 |
| **HeroUI v3** | `ui:primitive` | `react, tailwind-v4, headless, accessible` | 3 / 3 / 6 |
| **Evil-Buttons** | `ui:motion` | `playful, framer-motion, sound-physics` | 8 / 7 / 5 |
| **SmoothUI** | `ui:motion` | `framer-motion, shadcn-compatible, spring-physics` | 4 / 6 / 5 |
| **Tailark** | `ui:block` | `tailwind-v4, marketing, bento-grid` | 5 / 4 / 6 |

### 2. AST Static Analysis & Auto-Cross-Referencing

Using the TypeScript Compiler API (`ts.createSourceFile`), the parser statically extracts:
- **Exported Signatures**: Components, functions, and TypeScript prop interfaces.
- **Dependency & Graphic Tells**: Automatically identifies core imports (`framer-motion`, `motion/react`, `three`, `@react-three/fiber`, Radix UI, Ark UI).
- **Radix/Ark Primitive Binding**: When a component imports from `@radix-ui/react-*` or `@ark-ui/react`, those package names are automatically injected into `registryDependencies` and `peerDependencies`, ensuring clean downstream installation.
- **Three.js & WebGL Cross-Referencing**: When analyzing creative canvas and WebGL components, the parser automatically cross-references `threejs`, `webgl`, and `canvas` tags, injecting `three` into `dependencies` and `@types/three` into `devDependencies`.
- **`defaultDials` Preset Support**: If the parsed component belongs to a `KNOWN_REPOSITORIES` entry, the repo-level `defaultDials` preset is merged into the component's dial calibration before scoring overrides are applied.
- **`prefers-reduced-motion` Detection**: The parser scans for `prefers-reduced-motion` media query usage in both TSX source (`window.matchMedia`) and CSS-in-JS patterns. Components using this fallback automatically receive `reduced_motion_supported: true` in their accessibility contract and the `motion-safe` tag in their taxonomy.
- **Structural Complexity Scoring**: Evaluates mathematical loops (`requestAnimationFrame` with sinusoidal oscillations), shader code, and lines of code to score complexity as `low`, `medium`, or `high`.
- **Dynamic YAML Frontmatter Injection**: Formats component metadata, dial calibrations, and accessibility contracts directly into standard YAML frontmatter blocks.
- **Accessibility Markers**: WAI-ARIA roles, attributes, keyboard handlers, and `prefers-reduced-motion` fallbacks.


### 3. Normalization Codemods

Incoming code is sanitized automatically:
- **Tailwind v4 Converter**: Replaces legacy v3 arbitrary values (`p-[17px]`) with semantic system tokens
- **React 19 & Motion Adapter**: Migrates legacy `framer-motion` imports to `motion/react`
- **Attribution Injector**: Appends immutable SPDX open-source license and origin headers

### 4. Taste-Dial Scoring & Anti-Slop Gate

Components are scored on the three Taste Dials (1–10) and evaluated against the 21 Anti-Slop Rules:
- **Health Score**: Starts at 100 with deductions (15 for High, 8 for Medium, 3 for Low)
- **`defaultDials` Override**: Repo-level presets from `KNOWN_REPOSITORIES` are applied before per-component heuristics, ensuring library-wide dial consistency.
- **Automated Gating**: Any component with High-severity slop (`as any as`, fake TODOs, missing accessible labels, raw unshaded backgrounds) is blocked from ingestion.

## CLI Usage

```bash
# Harvest a specific repository
pnpm harvest repo smoothui

# Harvest a local directory
pnpm harvest dir ./packages/registry/src/creative

# Audit a single component file
pnpm harvest file ./packages/registry/src/motion/floating-dock.tsx

# List all configured upstream repositories
pnpm harvest list
```
