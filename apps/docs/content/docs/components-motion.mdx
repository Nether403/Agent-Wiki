# Motion & Physics (`ui:motion`)

The Motion category provides tactile, physics-based interactions calibrated via the `MOTION_INTENSITY` dial (1–10).

All motion components guarantee:
- **Reduced Motion Support**: `prefers-reduced-motion` compliance across all CSS animations and Framer springs.
- **GPU-Accelerated Transforms**: `transform` and `opacity` only; zero layout-triggering properties (`width`, `height`, `top`).
- **Smooth Layout Transitions**: Shared `layoutId` preservation without cumulative layout shifts.
