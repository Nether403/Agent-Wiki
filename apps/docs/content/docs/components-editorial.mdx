# Editorial & Architecture (`ui:editorial`)

Editorial components provide clear technical storytelling and high-density data formatting.

---

## Curated Components

- **`code-block`**: Syntax highlighting card with line numbers, filename badge, and copy confirmation.
- **`callout-card`**: High-contrast advisory callout supporting `info`, `warning`, `success`, and `danger` themes.
- **`minimal-table`**: Dense spreadsheet-style data grid with monospace numbers and sorting headers.
- **`data-stat-grid`**: SaaS KPI metric cards with directional trend indicators.
- **`diagram-card`**: Architecture flowchart container with interactive nodes.
