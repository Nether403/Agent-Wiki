# Headless Evaluation Sandbox & Benchmark

To mathematically verify that autonomous AI agents produce production-grade, zero-slop code without human intervention, the platform integrates a **Headless Evaluation Sandbox**.

---

## 1. Zero-Draft Fidelity Metric

**Zero-Draft Fidelity (0–100%)** measures the likelihood that an AI coding agent's very first code draft compiles without errors, passes strict accessibility checks, and satisfies all 50 Anti-Slop Rules.

$$\text{Fidelity Score} = (0.4 \times \text{SlopHealth}) + (0.3 \times \text{CompileSuccess}) + (0.3 \times \text{A11yPassRate})$$

- **Target Threshold**: $\ge 90\%$ Zero-Draft Fidelity.
- **Current System Benchmark**: **100% S-Grade**.

---

## 2. Running Evaluation via CLI

```bash
# Run the 10-prompt autonomous agent benchmark suite
npx design-wiki eval --suite benchmark

# Evaluate all local components in a directory
npx design-wiki eval ./components/ui --suite workspace
```

---

## 3. Evaluation Pipeline Stages

```
[Agent Generation] ──► [1. AST Anti-Slop Audit (50 Rules)]
                                │
                                ▼
                       [2. TypeScript Compiler (tsc --noEmit)]
                                │
                                ▼
                       [3. Axe-Core WCAG 2.1 AA Linter]
                                │
                                ▼
                       [4. Zero-Draft Fidelity Score (0-100%)]
```

---

## 4. MCP Tool Integration

Agents can trigger automated self-evaluations via the MCP tool `run_sandbox_evaluation`:

```json
{
  "tool": "run_sandbox_evaluation",
  "arguments": {
    "suite": "benchmark"
  }
}
```
