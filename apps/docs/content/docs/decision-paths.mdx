# Architectural Decision Paths

Rather than guessing UI layouts, AI coding agents and engineering leads use calibrated decision paths to select validated component combinations for specific application archetypes.

## 3. Querying via MCP Server

Agents running in Cursor, Claude Code, or Windsurf can invoke the `recommend_stack` MCP tool:

```json
{
  "archetype": "ai-chat-workspace",
  "primaryGoal": "Autonomous coding assistant with live code diff sandbox"
}
```

The tool returns the full component sequence, peer dependencies, and Tailwind CSS v4 variables ready for direct injection.
